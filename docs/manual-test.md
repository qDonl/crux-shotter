# 手动测试清单

## 标注

- [ ] 矩形：拖拽绘制描边矩形；小于 2pt 的拖拽不产生图形
- [ ] 箭头：拖拽绘制箭头，箭头头部方向正确
- [ ] 画笔：按住拖动绘制自由曲线；单击不产生线条
- [ ] 文字：点击处出现输入框，输入后按 Esc 或点击别处提交；空内容不添加
- [ ] 序号：单击依次添加 1、2、3
- [ ] 马赛克：拖拽区域，像素化与模糊两种模式均正确遮盖，且保存/复制的图片中同样生效
- [ ] 选择模式：点击矩形描边、箭头、画笔线条、文字、序号、马赛克区域可选中（蓝色虚线框）
- [ ] 移动：拖动已选标注，松开后位置更新；撤销一次即回到拖动前
- [ ] 缩放：选中矩形/马赛克出现 8 个白色方形手柄，拖动可缩放（拖过对边自动翻转）；选中箭头可拖动两端；画笔、文字、序号无手柄；一次缩放只需撤销一次
- [ ] 删除：选中后按 Delete / Backspace 删除该标注
- [ ] 改样式：选中标注后更换颜色/线宽，仅作用于该标注，撤销一次还原
- [ ] 撤销/重做：Cmd+Z / Cmd+Shift+Z 逐步撤销、重做各项操作
- [ ] 中文输入法：在截图选区层（及贴图编辑）中添加文字标注，用拼音输入法输入中文，候选框显示在选区层之上可见可选，组合中的文字正常显示，提交后内容正确
- [ ] 文字不自动换行：在靠近选区右边缘处输入一长串文字，输入时不换行（超出部分被裁掉），导出图片与输入时所见一致；只有回车才换行
- [ ] 序号重排：添加 1、2、3 后删除 2，剩余序号变为 1、2；撤销后恢复为 1、2、3

## 截图

（通过菜单栏「区域截图」或 ⌃⇧A 进入）

- [ ] 响应速度：触发后 150ms 内出现选区层（Instruments → Points of Interest，`com.cruxshot` 的 `capture-to-overlay` 区间）
- [ ] 冻结画面：选区层显示的是触发瞬间的屏幕，选区外为 40% 黑色遮罩，光标为十字
- [ ] 窗口吸附：悬停时窗口高亮（2pt 蓝色描边 + 浅蓝填充），单击直接选中该窗口；拖拽则框选任意区域
- [ ] 尺寸标签：选区左上角显示像素尺寸（如 `800 × 600`），Retina 屏上为点数的 2 倍
- [ ] 放大镜：选择阶段跟随光标，显示 15×15 像素 8 倍放大、网格和中心像素框，下方三行为像素坐标、颜色、选区尺寸；靠近屏幕右/下边缘时翻到另一侧
- [ ] 取色并复制：选择阶段按 C，颜色字符串写入剪贴板并退出选区层，右上角提示「已复制 #RRGGBB」（或当前格式的颜色字符串）
- [ ] HEX/RGB 切换：单独按一下 Shift，放大镜颜色在 `#RRGGBB` 与 `rgb(r, g, b)` 间切换；重新截图后保持上次格式
- [ ] 方向键微调：选中后方向键移动 1 像素，Shift+方向键移动 10 像素，Option+方向键调整宽高 1 像素
- [ ] 调整选区：拖动 8 个控制点或边缘可缩放（选中绘图工具时仅控制点和边框外侧可缩放，贴近边框内侧可正常绘制），未选工具时在选区内拖动可移动；添加标注后选区锁定（控制点消失），撤销全部标注后恢复可调
- [ ] 工具栏：位于选区下方 8pt，空间不够时在选区内底部；选中绘图工具出现第二行（6 色 + 3 档线宽，马赛克为像素化/模糊）；颜色/线宽在下次截图时保留
- [ ] 双击复制：未选绘图工具时在选区内双击，复制（含标注）并退出；双击标注本身、或双击结束文字编辑时不复制；选中绘图工具时双击不复制
- [ ] 快捷键：Enter 复制、⌘S 保存、⌘T 贴图、⇧⌘C 识别文字、⌘Z/⇧⌘Z 撤销重做、R/A/P/T/N/M 切换工具、Esc 退出
- [ ] 导出：复制到剪贴板的图片包含标注，像素尺寸与尺寸标签一致
- [ ] 双屏（含不同缩放比例，如 Retina + 1x 外接屏）：两块屏都出现选区层，可在任一屏选择；导出像素与所见一致；跨屏选区以中心点所在屏为准并裁到该屏
- [ ] 显示器变化：选区层打开时插拔显示器或改分辨率，选区层自动关闭
- [ ] OCR 模式：⌃⇧O 触发，松开鼠标即识别，不显示工具栏
- [ ] 提示（Toast）：出现在主屏右上角，不抢焦点，约 2.5 秒后淡出（带按钮时 4 秒），新提示替换旧提示

## 贴图

（通过选区工具栏「贴图」/ ⌘T，或「剪贴板贴图」⌃⇧P 生成贴图）

- [ ] 生成贴图：贴图出现在原选区位置、大小与所见一致，有阴影；当前前台 App 的焦点不丢失（例如编辑器里可继续打字）
- [ ] 拖动：按住贴图拖动可移动；关闭后用「恢复关闭的贴图」（⌃⇧Z）恢复，回到最后的位置
- [ ] 滚轮缩放：无修饰键滚动以光标为锚点缩放（光标下的图像点保持不动），范围 10%–500%；右下角显示百分比约 1 秒后消失
- [ ] 捏合缩放：触控板捏合同样以光标为锚点缩放
- [ ] 重置缩放：按 1 回到 100%
- [ ] 透明度：按住 ⌥ 滚动调整透明度，最低 10%、最高 100%
- [ ] 悬停：鼠标移入时出现 1pt 半透明描边，移出消失
- [ ] 旋转翻转：R 顺时针旋转、⇧R 逆时针旋转、H 水平翻转、V 垂直翻转；旋转时以窗口中心为基准改变宽高；旋转后再按 H 仍为屏幕上的左右翻转
- [ ] 点击穿透：按 T（或右键菜单勾选「点击穿透」）后鼠标点击穿透到下方窗口；按 ⌃⇧H 两次（隐藏再显示）后贴图恢复可交互，穿透取消
- [ ] 贴图上编辑：按 E 进入编辑，贴图下方出现精简工具栏（6 个绘图工具、撤销/重做、完成），第二行颜色/线宽/马赛克模式与截图时一致；可绘制所有标注类型，⌘Z/⇧⌘Z 撤销重做；点完成、Esc 或 Enter 结束编辑，标注保留在贴图上；再次按 E 可继续编辑已有标注
- [ ] 旋转后编辑：旋转/翻转的贴图按 E 时先恢复为 0°/不翻转显示，完成编辑后恢复原方向，标注随图一起旋转
- [ ] 缩放后编辑：在 200% 贴图上编辑，绘制位置与光标一致
- [ ] 右键菜单「复制」：剪贴板图片包含标注与旋转/翻转，像素尺寸为原图（旋转后宽高互换），不受缩放影响；提示「已复制」
- [ ] 右键菜单「保存」：按偏好设置的目录、格式与文件名模板保存，提示含路径和「在访达中显示」
- [ ] 右键菜单「识别文字」：识别结果写入剪贴板并提示；无文字时提示「未识别到文字」
- [ ] 右键菜单「点击穿透」「跟随切换桌面」：显示勾选状态，点击切换
- [ ] 右键菜单「关闭」、双击、Esc：均关闭贴图，且可用 ⌃⇧Z 恢复（含缩放、透明度、旋转、标注等状态）
- [ ] 快捷键：⌘C 复制、⌘S 保存
- [ ] 多贴图：同时存在多个贴图，各自独立缩放/移动/关闭；⌃⇧H 一次隐藏全部、再按显示全部；连续关闭多个后可依次恢复
- [ ] 切换桌面：勾选「跟随切换桌面」时切换 Space 后贴图仍可见；取消勾选后贴图固定在所在桌面

## 整体流程

- [ ] 菜单栏：图标为设置中所选的模板图标（默认「字母 C」，可选「剪刀」；随浅色/深色菜单栏自动反色）；菜单依次为 区域截图 / 全屏截图 / OCR 截图（均显示当前快捷键）— 剪贴板贴图、显示/隐藏贴图、恢复关闭的贴图、关闭全部贴图、贴图列表 — 设置…、检查更新…（未配置 Sparkle 公钥时为灰色，悬停提示「自动更新尚未配置」）— 退出 CruxShotter
- [ ] 切换菜单栏图标：设置 → 通用 →「菜单栏图标」在「字母 C」与「剪刀」间切换，菜单栏图标立即随之变化，重启后保持
- [ ] 区域截图 ⌃⇧A：出现选区层；结束后焦点回到触发前的 App（例如编辑器里可继续打字）
- [ ] 后台触发：在另一个 App（如编辑器、浏览器）处于前台时按 ⌃⇧A，选区层立即获得键盘焦点：Esc 退出、选区后 Enter 复制、R 切换矩形工具均生效（按键不会落到原 App）
- [ ] 全屏 App 上截图：在全屏（独立 Space）的 App 中按 ⌃⇧A，选区层覆盖该全屏 App（含菜单栏区域），可正常选区与导出
- [ ] 复制：Enter / 双击 / 工具栏复制后提示「已复制」，剪贴板图片含标注
- [ ] 保存：⌘S 保存到设置的目录，文件名符合模板、格式符合设置，提示「已保存」+ 路径 +「在访达中显示」（点击后 Finder 选中该文件）
- [ ] 贴图：⌘T 后贴图出现在原选区位置、大小一致
- [ ] 识别文字（标注模式 ⇧⌘C）：弹出「识别结果」面板，文字可编辑；「复制」保留换行，「复制为单行」合并为一行（中文之间不加空格）；再次识别替换面板内容
- [ ] 二维码：截取含二维码（URL）的区域识别，出现「识别到二维码」提示，点「复制链接」后剪贴板为该链接
- [ ] 取色：选择阶段按 C，提示「已复制 #RRGGBB」
- [ ] 全屏截图 ⌃⇧F：不出现选区层，直接复制光标所在屏幕，提示「已复制全屏截图」+ 像素尺寸；双屏时分别把光标放在两块屏上验证
- [ ] OCR 截图 ⌃⇧O：拖选后松开即识别，剪贴板为按行拼接的文字，提示「已复制文字」+ 前 3 行
- [ ] 剪贴板贴图 ⌃⇧P：复制图片后贴图出现在光标处居中、为原像素大小（Retina 下不放大）；复制文字后生成文字卡片（浅色外观白底、深色外观深底）；剪贴板为空或只有空白文字时提示「剪贴板没有可贴的内容」；靠近屏幕边缘时贴图不超出屏幕
- [ ] 剪贴板贴图 · 图片文件：Finder 中复制 1 张 png → 贴出原图；同时复制 3 张图片 + 1 个 txt → 贴出 3 张、依次向右下错开；复制 PDF → 贴出第一页；只复制 txt → 贴出文件名文字卡片，而不是文件图标；复制 12 张图片 → 贴出 10 张并提示「一次最多贴 10 张图片」
- [ ] 剪贴板贴图 · 颜色：分别复制 `#FF6A00`、`#F60`、`rgb(255, 106, 0)`、`rgba(255,106,0,0.5)`、`hsl(25, 100%, 50%)` → 贴出色卡（半透明显示棋盘格）；复制「颜色是 #FF6A00」→ 普通文字卡片
- [ ] 剪贴板贴图 · 富文本：从 Safari 网页、备忘录、Pages 复制带粗体/颜色/标题的文字 → 贴图保留格式；从深色主题的 VS Code 复制代码 → 深底卡片且文字清晰
- [ ] 剪贴板贴图 · 长文字：复制一大段无换行的文章 → 卡片宽度不超过约 640pt 并自动换行；复制代码 → 等宽字体
- [ ] 剪贴板贴图 · 大图：复制一张 6000px 宽的照片 → 贴图不超过屏幕的 80%，⌘C 复制贴图得到原像素尺寸
- [ ] 显示/隐藏贴图 ⌃⇧H、恢复关闭的贴图 ⌃⇧Z：与菜单项效果一致；没有可恢复的贴图时提示「没有可恢复的贴图」，菜单项为灰色
- [ ] 关闭全部贴图：全部关闭，之后可逐个恢复；没有贴图时菜单项为灰色
- [ ] 贴图列表：子菜单每项为「贴图 n（宽×高）」；对开启点击穿透的贴图点击该项后，贴图恢复可交互并位于最前；贴图全部隐藏时点击会先显示全部；没有贴图时「贴图列表」为灰色
- [ ] 贴图右键「保存」「识别文字」：与截图流程相同（保存提示同上；识别写入剪贴板并提示「已复制文字」）
- [ ] 重复触发：选区层打开时再按 ⌃⇧A / ⌃⇧F / ⌃⇧O 无反应，不会出现第二层选区
- [ ] 设置…：打开「CruxShotter 设置」窗口并位于最前；修改快捷键后菜单中显示的快捷键随之更新，新快捷键立即生效
- [ ] 快捷键冲突：在其他 App（如另一个截图工具）中占用 ⌃⇧A 后启动 CruxShotter，菜单栏图标右上角出现橙色圆点，设置页「区域截图」旁显示红色「与其他应用冲突」；改为未占用的组合后圆点和红字消失
- [ ] 浅色/深色外观：切换系统外观后，菜单栏图标、菜单、Toast、识别结果面板、设置窗口、权限引导窗口均正常显示

## 安装与权限

- [ ] 安装 DMG：打开 `CruxShotter-0.0.1-alpha.dmg`，把 CruxShotter 拖到「应用程序」
- [ ] Gatekeeper：首次打开被拦截（未公证的 ad-hoc 签名构建）；在「系统设置 › 隐私与安全性」点「仍要打开」后可启动（或执行 `xattr -dr com.apple.quarantine /Applications/CruxShotter.app` 后直接打开）
- [ ] 新构建重新授权：覆盖安装新的 alpha 构建后，需在「录屏与系统录音」中删除旧条目再重新添加并重启，截图才恢复正常


- [ ] 首次启动引导：`tccutil reset ScreenCapture com.cruxshot.CruxShot` 并 `defaults delete com.cruxshot.CruxShot cruxshot.onboardingShown` 后启动，自动出现「CruxShotter 需要屏幕录制权限」窗口，说明为「仅用于截取屏幕画面，所有数据只保存在本机。」
- [ ] 之后的启动（仍未授权）不再自动弹出；按任一截图快捷键或点截图菜单项时弹出引导窗口，不出现选区层
- [ ] 「打开系统设置」：触发系统授权请求并打开「隐私与安全性 › 屏幕与系统录音」
- [ ] 「我已授权，立即重启」：应用退出并重新启动（菜单栏图标重新出现），重启后截图正常；重启后不会误报快捷键冲突（无橙色圆点）
- [ ] 未授权时剪贴板贴图、显示/隐藏贴图、恢复贴图仍可使用（不需要屏幕录制权限）
- [ ] 运行中在系统设置里撤销权限后截图：出现引导窗口或「截图失败」提示，不崩溃

## 错误处理

- [ ] 保存回退：设置保存目录为不可写目录（如 `/System`），⌘S 后图片保存到「图片」，提示「保存位置不可写，已保存到「图片」」+ 路径
- [ ] OCR 无文字：对纯色区域 OCR 截图，提示「未识别到文字」，剪贴板内容不变；标注模式 ⇧⌘C 同样提示且不弹面板
- [ ] 截图时插拔显示器：选区层打开时插拔外接显示器（或改分辨率），选区层自动关闭，再次按快捷键可正常截图
- [ ] 截图失败：截图失败时提示「截图失败」+ 原因（可在 Console.app 中以 `com.cruxshot` 过滤看到 `capture failed` 日志）
