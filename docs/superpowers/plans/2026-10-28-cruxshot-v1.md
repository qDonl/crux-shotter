# CruxShot v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 CruxShot v1：面向开发者的 macOS 菜单栏截图工具，含区域/窗口截图、取色放大镜、标注、完整版贴图、OCR/二维码、设置与自动更新。

**Architecture:** 一个由 XcodeGen 生成的薄 App target（`App/`）+ 一个 Swift Package `CruxShotKit`（`CruxShotKit/`）。纯逻辑（坐标、选区、标注模型、贴图模型、按键映射、文件名、OCR）全部在 Package 中并用 Swift Testing 覆盖；AppKit 视图/窗口在 Package 中实现、靠手动测试清单验证；App target 只做入口、菜单栏、权限引导、Sparkle。

**Tech Stack:** Swift 6.1、AppKit、SwiftUI、ScreenCaptureKit、Vision、Core Image、Swift Testing、XcodeGen、KeyboardShortcuts 2.x、Sparkle 2.x。

**Spec:** `docs/superpowers/specs/2026-10-28-cruxshot-v1-design.md`

## Global Constraints

- 最低系统 macOS 14.0（`platforms: [.macOS(.v14)]`，`MACOSX_DEPLOYMENT_TARGET = 14.0`）
- Swift 6 语言模式；所有 AppKit 视图/窗口/控制器类型标注 `@MainActor`
- 第三方依赖仅 `sindresorhus/KeyboardShortcuts`（from: "2.0.0"）与 `sparkle-project/Sparkle`（from: "2.6.0"），不得新增
- 截图只用 `SCShareableContent` + `SCScreenshotManager`，禁止 `CGWindowListCreateImage`
- Bundle ID `com.cruxshot.CruxShot`；日志 `Logger(subsystem: "com.cruxshot", category: <模块名>)`
- App 为 `LSUIElement = YES`（无 Dock 图标）
- 不做任何遥测与崩溃上报
- 许可证 MIT
- 坐标约定：模块间传递的屏幕坐标一律为 **AppKit 全局坐标（points，原点在主屏左下角）**；画布内坐标为 **图像坐标（points，原点在图像左上角）**
- 默认全局快捷键：区域截图 `⌃⇧A`、全屏 `⌃⇧F`、OCR `⌃⇧O`、剪贴板贴图 `⌃⇧P`、隐藏/显示贴图 `⌃⇧H`、恢复贴图 `⌃⇧Z`
- 默认保存：PNG，`~/Desktop/CruxShot/`，文件名 `CruxShot 2026-10-28 21.03.15.png`；回退目录 `~/Pictures`
- 测试命令统一为 `swift test --package-path CruxShotKit --filter <Suite>`

## Review Focus

1. **混合缩放比例的多屏**（Retina 内建屏 + 1x 外接屏，外接屏在主屏上方/左侧、坐标为负）：选区跨屏或位于副屏时，导出像素必须与所见一致 → Task 2 `pixelRectOnNegativeOriginDisplay`、Task 10 `selectionClampedToUnionOfDisplays`。
2. **在桌面空白处单击（无窗口可吸附）或极小拖拽**：不应产生 0×0 选区或导出空图 → Task 10 `tinyDragIsTreatedAsClick`、`clickWithoutWindowKeepsSelectingPhase`。
3. **保存目录不存在或不可写**：不存在时自动创建；不可写时回退 `~/Pictures` 并告知 → Task 7 `createsMissingDirectory`、`fallsBackWhenUnwritable`。
4. **剪贴板文字超大**（上万行、单行几千字符）：贴图不应卡死或生成超大图片 → Task 13 `truncatesTo80Lines`、`truncatesLongLines`。
5. **OCR 无文字 / 撤销栈边界**：OCR 空结果不改剪贴板；连续撤销到底、撤销后新操作清空 redo → Task 8 `blankImageReturnsNoLines`、Task 5 `newEditClearsRedo`、`undoOnEmptyIsNoop`。

### Task 6: 标注渲染（含马赛克）

**Files:** Create `Canvas/AnnotationRenderer.swift`；Test `AnnotationRendererTests.swift`

**Interfaces:**
- Consumes: `AnnotationDocument`、`Annotation`
- Produces: `public enum AnnotationRenderer { static func draw(_ annotations: [Annotation], source: CGImage, scale: CGFloat, in ctx: CGContext); static func render(_ doc: AnnotationDocument) -> CGImage }`
  - `draw` 在图像坐标系（points，左上原点）中绘制，供 `CanvasView` 实时显示；`render` 生成与 `doc.image` 同像素尺寸的最终图（ctx 缩放 `scale`）。
  - 马赛克：从 `source` 裁出对应像素区域，`.pixelate` 用 `CIPixellate`（块大小 = 12pt × scale），`.blur` 用 `CIGaussianBlur`（半径 = 10pt × scale，先 `clampedToExtent` 再裁回），结果画回原位。所有标注按数组顺序绘制；马赛克取样始终来自 `source` 原图（不会把先画的箭头等一起模糊）。
  - 箭头：线 + 实心三角箭头（头长 = 4 × lineWidth，最小 12pt）；序号：实心圆（直径 = 2.2 × fontSize）+ 白色居中数字；文字：`NSAttributedString` 用 `.systemFont(ofSize: fontSize, weight: .semibold)`，支持换行。
