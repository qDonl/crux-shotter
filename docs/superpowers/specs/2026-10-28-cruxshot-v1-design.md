# CruxShot v1 设计文档

- 日期：2026-10-28
- 状态：待审阅

## 1. 背景与目标

CruxShot 是一款面向**开发者 / 效率党**的 macOS 截图工具，开源免费（MIT），通过 GitHub Releases 与 Homebrew cask 分发，不上架 Mac App Store。

v1 的目标：把「截图 → 标注 → 贴图 / OCR → 复制」这条高频主路径做到快、准、顺手。

**成功标准**
- 按下截图快捷键到选区层出现 ≤ 150ms（Apple Silicon，双屏）
- 选区层显示的画面与最终导出的像素完全一致
- 贴图、OCR、复制等核心操作全部可用键盘完成

**约束**
- 最低系统：macOS 14 Sonoma
- 技术栈：Swift 6，AppKit 负责核心交互，SwiftUI 负责外围 UI
- 第三方依赖仅：KeyboardShortcuts（全局快捷键）、Sparkle（自动更新）
- 不采集任何遥测 / 崩溃数据

## 2. 范围

### v1 包含
- 区域截图 + 窗口吸附、全屏截图
- 选区放大镜、像素坐标、尺寸、取色；方向键微调
- 标注：矩形、箭头、画笔、文字、序号、马赛克/模糊；撤销/重做
- 输出：复制、保存
- 贴图完整版：截图贴图、剪贴板贴图（图片/文字）、缩放/透明度/旋转/翻转、点击穿透、贴图上再标注、多贴图管理、恢复关闭、跟随 Spaces
- OCR（Vision，离线，中英文）+ 二维码识别
- 菜单栏常驻、可自定义全局快捷键、设置面板、权限引导、Sparkle 自动更新

### v1 不包含（v2+）
- **录屏 / GIF**
- 长截图 / 滚动截图
- 像素尺子（测量间距）
- 截图历史
- UI 元素级识别（Accessibility）
- AI 智能打码、美化背景
- 云分享

> 注：v1 仍需申请系统的「屏幕录制」权限——这是 macOS 对任何截图 API（ScreenCaptureKit）的要求，并不意味着实现录屏功能。

## 3. 架构

工程由一个薄的 Xcode App target 与一个 Swift Package 组成，核心逻辑全部在 Package 中，可用 `swift test` 直接测试。

```
CruxShot.app（App 外壳：入口、菜单栏、权限、Sparkle）
└── CruxShotKit（Swift Package）
    ├── Capture      ScreenCaptureKit 封装：枚举屏幕/窗口，产出 CapturedFrame
    ├── Overlay      截图选区层：选区、窗口吸附、放大镜、取色、微调
    ├── Canvas       标注模型 + 渲染 + 撤销/重做（Overlay 与 Pin 共用）
    ├── Pin          贴图窗口、PinManager、剪贴板转贴图
    ├── Recognition  OCR + 二维码（Vision）
    ├── Output       剪贴板、保存文件、文件名模板
    └── Settings     偏好（UserDefaults）、快捷键定义、SwiftUI 设置界面
```

### 3.1 模块协作
- `AppCoordinator` 串联流程：快捷键 → `Capture` → `Overlay` → 用户动作（复制 / 保存 / 贴图 / OCR）→ 对应模块。
- 模块之间只通过小接口通信，不访问彼此内部实现：
  - `Capture` 只产出 `CapturedFrame`（图像、屏幕全局 frame、`backingScaleFactor`），不关心消费者。
  - `Canvas` 是纯数据模型（`AnnotationDocument`），渲染与模型分离，Overlay 和 Pin 都持有它。

### 3.2 关键技术决策
- **冻结画面截图**：按下快捷键瞬间对所有屏幕截图并获取窗口列表（按 z-order），选区层显示这张静态画面。放大镜、取色、窗口吸附和最终导出都基于同一份数据。
- **多屏幕**：每块屏幕一个 overlay 窗口；内部统一使用全局坐标，按各屏 `backingScaleFactor` 换算到像素。
- **截图 API**：`SCShareableContent` 获取屏幕和窗口，`SCScreenshotManager` 截图（macOS 14+），不使用已弃用的 `CGWindowListCreateImage`。

## 4. 截图流程与交互

### 4.1 默认全局快捷键（均可在设置中修改）

| 快捷键 | 功能 |
|---|---|
| `⌃⇧A` | 区域截图（带窗口吸附） |
| `⌃⇧F` | 全屏截图（光标所在屏幕，直接复制） |
| `⌃⇧O` | OCR 截图（框选后直接复制文字） |
| `⌃⇧P` | 剪贴板内容贴图 |
| `⌃⇧H` | 隐藏 / 显示全部贴图 |
| `⌃⇧Z` | 恢复最近关闭的贴图 |

### 4.2 选区阶段
- 鼠标悬停时高亮其下方的窗口，单击选中该窗口；拖拽为自由框选。
- 光标旁放大镜：8 倍放大 + 像素网格；下方显示坐标、颜色、选区尺寸（实际像素）。
- `C` 复制颜色值；单独按下并松开 `Shift`（不与其他键组合）切换 HEX / RGB 显示格式。
- 方向键移动选区 1px，`⇧`+方向键移动 10px，`⌥`+方向键调整选区大小。
- `Esc` 取消。

### 4.3 选区完成后
- 选区边缘可拖动调整；选区下方出现工具栏：

  `[矩形][箭头][画笔][文字][序号][马赛克] | [撤销][重做] | [OCR][贴图][保存][复制✓]`

- `Enter` / 双击：复制并关闭（默认操作）
- `⌘S` 保存，`⌘T` 贴图，`⌘⇧C` OCR，`⌘Z` / `⌘⇧Z` 撤销 / 重做
- 工具快捷键：`R` 矩形、`A` 箭头、`P` 画笔、`T` 文字、`N` 序号、`M` 马赛克

### 4.4 OCR 与二维码
- `⌃⇧O`：识别结果直接写入剪贴板，右上角提示显示前几行。
- 工具栏 OCR：弹出可编辑文本面板，提供「复制」「复制为单行」。
- 选区内检测到二维码时，提示中额外提供「复制链接」。
- 识别语言：简体中文、繁体中文、英文；使用 `VNRecognizeTextRequest`，`.accurate` 级别。

### 4.5 保存
- 默认 PNG，保存到 `~/Desktop/CruxShot/`，文件名 `CruxShot 2026-10-28 21.03.15.png`。
- 路径、格式（PNG / JPG）、文件名模板可在设置中修改。

## 5. 标注画布（Canvas）

### 5.1 数据模型
- `Annotation`：`id`、`kind`（rect / arrow / pen / text / counter / mosaic）、几何信息、样式（颜色、线宽、字号）。
- `AnnotationDocument`：原图 + 有序的 `[Annotation]`。
- 撤销 / 重做基于对标注列表的操作记录（添加、删除、移动、改样式），纯数据，可单元测试。

### 5.2 交互
- 已画的标注可选中、拖动、缩放、`Delete` 删除、修改颜色。
- 预设 6 种颜色（默认红色），线宽细 / 中 / 粗三档；上次的选择会被记住。
- 序号每次点击自动 +1；删除某个序号后其余序号重新编号。
- 文字：点击后直接输入，支持中文输入法与多行。
- 马赛克：像素化 / 高斯模糊两种模式，基于原图区域实时计算；导出时直接合成进最终图片，不保留独立图层，原文不可还原。

### 5.3 导出
- 按原始像素分辨率合成最终图片（Retina 为 2 倍），复制、保存、贴图都使用这张图。

## 6. 贴图（Pin）

### 6.1 窗口
- 无边框 `NSPanel`，层级为 `.floating`，`nonactivatingPanel`：不抢走当前应用的焦点。
- 有阴影；鼠标悬停时显示细边框。

### 6.2 操作

| 操作 | 效果 |
|---|---|
| 拖动 | 移动 |
| 滚轮 / 触控板捏合 | 缩放 10%–500%，角落短暂显示比例 |
| `⌥`+滚轮 | 调透明度 |
| `1` | 恢复原始大小 |
| `R` / `⇧R` | 顺时针 / 逆时针旋转 90° |
| `H` / `V` | 水平 / 垂直翻转 |
| `E` | 进入标注编辑（复用 Canvas，也可右键「编辑标注」） |
| `T` | 开关点击穿透 |
| 双击 / `Esc` | 关闭 |
| 右键 | 菜单：复制、保存、OCR、点击穿透、跟随切换桌面、关闭 |

- **点击穿透**开启后贴图不接收鼠标事件。退出方式：菜单栏「贴图列表」，或 `⌃⇧H` 隐藏后再显示——显示时所有贴图的点击穿透都恢复为关闭。

### 6.2.1 贴图编辑
- 截图生成的贴图保存原图和标注（不合成），截图时画的标注在贴图上仍可选中、移动、缩放、改颜色、删除，序号接着编号。
- 编辑工具栏与截图时一致：工具 | 撤销 重做 | 识别文字、保存、复制 | 完成；快捷键同截图：`R A P T N M`、`⌘Z`/`⇧⌘Z`、`⇧⌘C` 识别、`⌘S` 保存、`⌘C` 复制。
- `↩` 或 ✓ 完成并保留修改；`Esc` 放弃本次进入编辑以来的所有修改（之前的标注不受影响）；文字输入中 `Esc` 只结束文字输入，选中标注时 `Esc` 只取消选中。
- 识别文字 / 保存 / 复制：保留修改、退出编辑，再对带标注的结果执行，贴图保留。

### 6.3 剪贴板贴图（`⌃⇧P`）
按以下优先级识别剪贴板内容：
1. **Finder 中复制的图片文件**（png/jpg/heic/pdf 等）：每个文件一张贴图，第一张以光标为中心，其余依次向右下错开 24pt；PDF 取第一页；非图片文件忽略；一次最多 10 张，超出时提示。剪贴板有文件但都不是图片时，不贴 Finder 附带的文件图标。
2. **图片数据**：直接贴出。
3. **颜色值**（整段文字恰好是一个颜色：`#RGB`、`#RGBA`、`#RRGGBB`、`#RRGGBBAA`、`rgb()/rgba()`、`hsl()/hsla()`）：贴出色卡，上方色块（半透明时叠棋盘格），下方显示 HEX 与 RGB 值。
4. **富文本**（RTF 优先，其次 HTML）：保留原字体、字号、颜色等格式；默认白底，文字以浅色为主时（如从深色主题编辑器复制）用深底。
5. **纯文字**：代码样式（有缩进或行尾为 `{` `}` `;`）用等宽字体，其他用系统字体；配色跟随系统浅色 / 深色外观。

文字卡片超过 640pt 宽自动换行，最多 80 行，超出部分以「…（共 N 行）」结尾。图片超过所在屏幕可见区域的 80% 时按比例缩小显示，像素不丢弃。剪贴板为空或格式不支持：提示「剪贴板没有可贴的内容」。

### 6.4 多贴图管理
- `PinManager` 统一管理：`⌃⇧H` 隐藏 / 显示全部，菜单栏「关闭全部贴图」。
- 关闭的贴图进入最近关闭栈（最多 10 张，仅存于内存），可通过菜单栏或 `⌃⇧Z` 恢复。
- 每张贴图可单独设置是否跟随切换桌面（`canJoinAllSpaces`），默认跟随。

## 7. 权限

- v1 只需要**屏幕录制**权限。全局快捷键基于 Carbon 热键（KeyboardShortcuts），不需要辅助功能权限。
- 首次启动显示 SwiftUI 引导窗口：说明用途 → 按钮跳转到「系统设置 → 隐私与安全性 → 录屏与系统录音」→ 授权后提示「立即重启」。
- 每次截图前用 `CGPreflightScreenCaptureAccess()` 检查；未授权时不弹出选区层，改为打开引导窗口。

## 8. 错误处理

| 情况 | 处理 |
|---|---|
| 截图失败（被拒绝、屏幕切换中） | 右上角提示「截图失败：原因」，写日志，不崩溃 |
| 快捷键注册失败（冲突） | 设置中该快捷键标红，菜单栏图标显示提醒标记 |
| 保存路径无写入权限 / 不存在 | 回退保存到 `~/Pictures`，并提示 |
| OCR 未识别到文字 | 提示「未识别到文字」，不修改剪贴板 |
| 截图过程中屏幕配置变化 | 取消本次截图 |

- 日志使用 `os.Logger`，subsystem `com.cruxshot`。
- 不做任何遥测和崩溃上报。

## 9. 测试

**单元测试**（Swift Testing，位于 CruxShotKit，`swift test` 运行）
- Canvas：增删改标注、撤销 / 重做、序号重排
- 坐标换算：多屏、Retina、选区 → 像素矩形
- 窗口吸附：给定点命中正确窗口（按 z-order）
- 文件名模板、颜色格式转换
- OCR：固定测试图片验证中英文识别

**手动测试**：`docs/manual-test.md` 清单，每次发版前执行；覆盖单屏 / 双屏、Retina / 非 Retina、浅色 / 深色外观。
