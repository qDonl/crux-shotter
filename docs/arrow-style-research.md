## 对 CruxShotter 的设计建议

以下是综合判断，不是上述厂商的官方结论。

### 建议提供的可比较候选

这些名称与下述九种具体形状均为 **CruxShotter 自有设计候选**，不是逐一映射某家软件的已确认同款。正交折线、具体渐粗轮廓和块箭比例是本项目场景推导。

| 候选 | 视觉特征 | 优先场景 | 取舍 |
|---|---|---|---|
| 经典实心 | 等宽线身、实心三角尖头，延续当前箭头 | 日常指出按钮、代码行、错误位置 | 熟悉、稳定；较粗时需要避免头部遮住目标。 |
| 精细开口 | 纤细等宽线身、开口尖头 | 小控件、密集表格、像素级问题反馈 | 遮挡少；缩小后要检查可辨认性。 |
| 渐粗聚焦 | 从细尾部向尖头方向饱满过渡 | 重要结论、演示、较长距离指向 | 指向更鲜明；应限制最大粗细与头部尺寸。 |
| 饱满块箭 | 填充式块状箭身、宽大尖头 | 面向非技术用户的教程、大图演示 | 缩小后仍醒目；不适合密集代码和细小目标。 |
| 弧线指引 | 平滑单弧路径、沿末端切线方向的尖头 | 绕开文字、跨区域关联 | 减少遮挡；需一个明确的弯曲控制点。 |
| 直角折线 | 水平 / 垂直线段组成，转角轻微圆润 | UI 评审、字段关联、流程关系 | 对齐整齐；须避免多条折线交叉和箭头贴边。 |
| 双向对照 | 两端尖头、等宽线身 | 距离范围、前后对照、双向联系 | 语义鲜明；不能替代普通的单点指示。 |
| 虚线关联 | 均匀短划线、明确尖头 | 可选流程、间接关联、辅助引导 | 区分主次；短箭头要保证至少有可辨认的划线。 |
| 手绘弧箭 | 有控制的轻微不规则弧线，末端方向准确 | 教学讲解、轻松反馈、社交分享 | 更有亲和力；不作为技术截图的默认样式。 |

对比描边是全体候选共享的可选效果，用于复杂背景，不单独占一个“箭头种类”。

### 更适合当前简洁 UI 的组织

- 主工具架继续只有一个箭头入口，不增加多个箭头工具。
- 样式弹出面板用“缩略图 + 名称”，允许用户先选 3–5 个常用预设；颜色和线宽继续使用现有控件。
- 直线 / 曲线、单向 / 双向、实线 / 虚线属于可以组合的属性。首版可以只暴露选定的预设，避免把所有组合平铺。
- 所有箭头按“尾部拖向目标”绘制；拖拽时实时预览。Shift 吸附角度，选中后拖两个端点；曲线额外给一个中间弯曲点。
- 头部尺寸随线宽变化，同时受箭长约束；短箭头避免头尾互相吞没。长箭头保持有限粗细；透明图、浅色和深色背景都应检查。
- 默认不加阴影、渐变或强描边。复杂照片上的高对比轮廓可以作为后续可选效果，而不是独立堆叠多种花哨样式。
- 样式切换保留端点和当前位置；只作用于当前选中的箭头，并能一次撤销。截图与贴图编辑必须使用同一套渲染规则。

推荐首期选择：经典实心、精细开口、渐粗聚焦、弧线指引、直角折线、双向对照。饱满块箭、虚线关联和手绘弧箭作为备选，由用户按场景决定。

## 用户选定范围

2026-10-31 用户通过设计预览选定：A 经典实心、B 精细开口、C 渐粗聚焦、G 双向对照、H 虚线关联、I 手绘弧箭。实现仅包含这六项；经典实心作为默认，其后记住最近选择。对比描边在预览中未开启，本轮不增加该效果。
