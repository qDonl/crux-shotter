# 标注操作区：贴角双层

用户在 2026-11-01 选定「贴角双层」方案。前一轮[竞品一手资料核查](annotation-ui-competitor-research.md)确认：Flameshot 把当前工具选项和颜色放在同侧可收起栏，Shottr 在选中对象后显示属性，Snipaste 使用 `1` / `2` 与滚轮调线宽。这些是交互参考；本项目的贴角双层布局为 CruxShotter 自有设计。

## 结构

- 选区左下角附近只有一块浅色细边框工具板。上排是选择、矩形、箭头、画笔、文字、序号、马赛克七个纯图标入口；下排只显示当前工具或所选标注适用的属性。
- 箭头下排直接并列六种形状预览与六个颜色点；序号下排直接并列三种样式与六个颜色点；矩形、画笔、文字只显示颜色；马赛克显示像素化、模糊。无需打开第二个弹窗。
- 没有绘制工具且未选中标注时，下排收起。输出操作仍为独立的短工具条，与工具板避让摆放。
- 无常驻线宽数值或滑杆。`1` / `2`、`[` / `]`、滚轮继续实时调线宽，光标旁短暂显示反馈。

## 状态与操作

1. 点工具后马上进入该绘制模式；再次点同一图标保持模式。用选择图标或 `V` 切到选择模式。画完一个标注仍保持工具激活，空白处可直接继续绘制。
2. 新建状态下，下排显示后续标注的默认属性。点击样式或颜色立即改变默认值，重启后保持最近设置。
3. 选中旧标注时，下排显示这条标注的实际属性，优先于当前绘制工具。更改只影响所选标注，支持撤销；默认值不被悄悄改写。按 `Esc` 取消选中后，下排恢复绘制默认值。
4. 点击已有标注优先选择或移动；按住 `Option` 可覆盖绘制。文字输入期间数字键正常输入，不触发线宽调整。
5. 截图界面和贴图编辑共用这块工具板与操作规则。选区大小或屏幕位置变化时，在可见区域内优先贴近选区下方、避免与输出条重叠；空间不足时移到选区上方或画面边缘。

## 视觉

近白色表面、1 pt 中性描边、约 4 pt 圆角。图标按钮约 32 pt；当前工具或样式只用细底线标识。箭头缩略图取自实际绘制几何，序号缩略图取自实际序号几何。颜色以单排圆点表达，按钮保留悬停提示与辅助功能名称。布局不使用深色底块、长文字说明或大阴影。

## 实现与验收

`ToolbarView` 的 `toolRack` 包含工具行和上下文属性行，不再创建独立属性面板或三个弹出面板。`OverlayController`、`PinEditor` 使用同一组件；`ToolbarLayout` 将工具板与输出条配对摆放。`CanvasView` 按是否选中标注区分编辑对象与新建默认值，选中的马赛克也可直接切换模式。

`v0.0.10-alpha` 已通过 Swift Package 226 项测试、Release App 编译、代码签名校验及 DMG 完整性校验。未做真实 UI 自动化；实际鼠标、键盘、输入法及视觉体验由用户本地验收。重点检查普通 / 极小 / 全屏选区、多显示器、贴图编辑、画后连续绘制、选中与取消选中状态、当前样式高亮以及 `1` / `2` 实时反馈。
