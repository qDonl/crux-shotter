# CruxShotter 需求、界面决策与实现状态

更新：2026-11-01。本文汇总本轮对话中用户确定的调整要求，并以 `v0.0.8-alpha` 的代码为状态基准。早期方案见 `docs/superpowers/specs/2026-10-28-cruxshot-v1-design.md`；两者冲突时，以本文记录的后续用户选择为准。

## 1. 产品与协作边界

- 产品是 macOS 菜单栏截图工具，核心路径为选区、标注、复制 / 保存 / 贴图 / OCR。截屏权限由系统的「录屏与系统录音」管理；截图功能本身不是录屏功能。
- 用户负责运行中的界面和端到端自动化验收。开发侧负责实现、单元 / 组件测试、编译和逻辑检查；不再用 UI 自动化替用户验证。
- 用户要求工作区干净：构建后清理历史中间产物，只保留当前需要交付的安装包与校验文件。发布需提交代码、推送分支、推送 release 包。
- 视觉目标是简单、轻巧、线条感强。截图中的操作应围绕选区，尽量少遮挡画面，减少工具条的直接文字与黑色大块背景。

## 2. 截图界面：已经选定的方案

| 部位 | 用户确定的体验 | `v0.0.8-alpha` 状态 |
|---|---|---|
| 整体布局 | 「分离工具架」与「边角线控」：绘图、属性、输出分别放置，靠近选区但互不挤占；极小选区、贴边和全屏时应留在屏内。 | 已实现三组独立控件和避让布局；组件布局测试覆盖常见边界。 |
| 视觉 | 浅色细边框、轻量表面、纯图标。工具条不使用黑色底块；工具与箭头样式面板不堆长文字。 | 已实现浅色窄工具架、纯图标按钮、悬停提示及辅助功能名称。 |
| 模式 | 明确区分「选择 / 移动」与绘图模式。工具架提供选择入口；`V` 返回选择模式。 | 已实现；绘图工具可按快捷键切换。 |
| 属性 | 单个颜色点作为入口，展开紧凑的六色色盘；箭头样式和马赛克模式只在相关上下文出现。 | 已实现单色点、三列色盘、条件显示的属性栏。 |
| 箭头菜单 | 工具架只放一个箭头入口；样式用形状预览组成 2 列 × 3 行纯图标面板。 | 已实现；样式名放在悬停提示和辅助功能标签中。 |
| 选区轮廓 | 细边框和四角短线提示截图边界；调整范围后，标注仍应对应原来的屏幕内容。 | 已实现四角短线、拖动选区和重新裁切。 |
| 控制点显隐 | 用户曾明确选「靠近才显示」，期望控制点在光标接近可操作位置时出现，平时保持画面干净。 | **尚未完全兑现**：当前选区四角方形控制点在调整阶段常显；选中标注的角点也常显。需继续按此偏好改进，并做实际视觉验收。 |

### 选区与标注的命中规则

1. 创建选区后，四角与边缘仍可调整截图范围；标注已存在时也一样。重新裁切从冻结的原屏幕快照取像素，标注保持在对应的全局屏幕位置；缩小后暂时位于选区外的标注，重新扩大选区仍能出现。
2. 选择模式下，选区内空白处可拖动整个选区；命中标注或其控制点则交给标注编辑。绘图模式下，选区边框外侧与角点可改范围，边框内侧用于绘图。
3. 更改选区、移动标注、调整标注几何、修改样式应支持撤销 / 重做。导出图像必须与当前选区及标注所见一致。

## 3. 标注编辑与连续绘制

以下是用户反复强调的主流程，应作为后续改动的回归标准：

1. 选定矩形、箭头、画笔、文字、序号或马赛克工具后，在空白处绘制 / 点击创建。完成一个标注后，**工具仍保持激活**，新标注进入选中状态。
2. 鼠标松开后，可直接改当前标注的颜色 / 线宽或拖动它；无需再次点工具条。选中矩形内部也可拖动，箭头沿线段可拖动，文字完成输入后可拖动。
3. 在空白处再次绘制，立即新增同类标注；可连续添加箭头、方框和文字。点击已有标注优先选择或移动它；需要在已有标注上起笔覆盖绘制时按住 `Option`。
4. 文字输入结束时保留该文字的选中状态和文字工具。点击空白处结束当前输入后，再点击可开始下一段文字；文字输入时数字键要正常输入字符。
5. 显式切换到选择模式后，可选择、移动、缩放和删除标注。矩形 / 马赛克显示角点，边缘仍可命中缩放；箭头有两个端点，手绘弧箭额外有弯曲控制点。重叠标注可通过 `Tab` / `Shift+Tab` 轮换选中。
6. `Esc` 按当前状态逐级处理文字输入、标注选择、绘图模式和截图界面，不应意外丢失已完成的内容。

当前代码在 `CanvasView`、`OverlayController` 中实现上述连续绘制及画后编辑；`PostDrawEditingTests` 覆盖矩形 / 箭头「画完 → 改线宽 → 移动 → 再画」和文字「输入 → 完成 → 移动 → 再输入」。这些是组件验证，用户仍需验收真实鼠标、键盘和输入法操作。

### 线宽的实时控制

- 不在工具条常驻展示线宽滑杆或宽度文字。`1` / `[` 逐级减小，`2` / `]` 逐级增大；画布内滚轮也可调节。范围为 1–12pt，每次变动 1pt，光标旁短暂显示线宽数值。
- 矩形、箭头、画笔在鼠标按下且尚未松开时，按键应立即改变**当前正在画的笔画**，不能只作用于下一笔；松开后的最新值也应保留。
- 松开后刚画好的线条处于选中状态，同样可实时调整它的线宽。连续交替按 `1 → 2 → 1 → 2`，每次都必须生效，不能只能朝一个方向调整。
- 已选标注的线宽以它自己的当前值为步进基准；未选标注时以绘图默认值为基准。修改线宽不能重置颜色或箭头样式。文字输入阶段不截获数字键；不支持线宽的标注不会因滚轮改变粗细。
- 截图和贴图再编辑使用同一套规则；最近设置会被记住。

当前实现包含拖动中草稿实时更新、选中标注实时更新、从叠层和贴图编辑入口转发快捷键。`LineWidthInteractionTests` 验证交替按键、绘制中的可见笔画变化和松开后的结果；仍需用户在实际截图窗口中验证。

## 4. 箭头样式

用户从多个候选中选定六种，按用途保持明显区别：

| 样式 | 主要场景 |
|---|---|
| 经典实心 | 普通指向，默认样式。 |
| 精细开口 | 小目标、密集内容，减少遮挡。 |
| 渐粗聚焦 | 强调重点，尾部到箭头逐渐变粗。 |
| 双向对照 | 表示两端关系或范围。 |
| 虚线关联 | 次要路径或间接关联。 |
| 手绘弧箭 | 轻松表达或绕开内容；可拖中间控制点改变弧度。 |

每条箭头单独保存样式与弯曲程度；切换已选箭头样式只改该箭头并可一次撤销，未选择时更改后续绘制默认值。颜色、线宽、箭头样式分别修改，截图和贴图编辑、预览与导出使用同一几何生成规则。未选入的块箭、普通弧线、直角折线和额外描边不进入当前面板。设计背景与选型记录见 [箭头样式研究](arrow-style-research.md) 和 [六种样式规格](arrow-styles.md)。
