# 六种箭头样式

用户确认范围：经典实心、精细开口、渐粗聚焦、双向对照、虚线关联、手绘弧箭。默认经典实心；不加入候选中的块箭、普通曲线、直角折线或未开启的描边。

## 使用方式

- 工具架仍只有一个箭头入口（A）。属性行增加一个带缩略图的样式按钮，弹出六项原生菜单。
- 每个箭头单独保存样式和手绘曲率。选择已有箭头时，工具栏显示它的样式、颜色和线宽。
- 切换样式仅影响选中箭头，并可一次撤销；未选择箭头时仅修改后续绘制默认值。最近选择通过 Preferences 持久化。
- 手绘弧箭有两个端点和一个中间弯曲控制点；弯曲是相对箭长的有符号比例，移动不改曲率，端点调整时按比例保持。每次重绘 / 导出形状确定，不使用随机噪声。
- 颜色、线宽和箭头类型分别修改，避免改变一个属性时重置其他属性。

## 实现

`ArrowGeometry` 统一生成线条、填充尖头、选中边界和命中区域，供画布、导出和菜单缩略图共用。短箭头限制线宽和尖头尺寸；双向箭头给两端预留空间；虚线仅用于箭身，尖头保持实心，虚线间隙仍可命中以方便选择。

`AnnotationKind.arrow(from:to:)` 保留原接口；新增样式枚举和独立曲率，撤销 / 重做、移动、端点缩放和贴图再次编辑均保留这些数据。
