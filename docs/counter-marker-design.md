# 序号标记样式设计提案

日期：2026-11-01。状态：三款样式已实现，等待用户在真实应用中验收。用户从初版预览中选择了「细线圆环」与「数字短线」两个方向，并要求重新细化外观。下列尺寸均为截图画布上的逻辑点（pt），预览展示个位数、两位数和三位数。

## 目标

- 与截图界面的浅色细线、纯图标设计保持一致，标记本身轻巧，放在密集界面上仍可辨认。
- 两种风格有明确用途：圆环适合独立步骤，数字短线适合在局部界面上做轻量指示。
- 复杂照片、浅色和深色画面中，数字与边界都要稳定可读；不依赖截图软件当前的浅色 / 深色外观决定导出颜色。
- 连续编号、移动、删除后重排、撤销 / 重做、截图与贴图再编辑保持一致。

## 精修候选

| 候选 | 形态 | 尺寸与细节 | 取舍 |
|---|---|---|---|
| 精密圆环 | 完整细环，数字居中；近白色 97% 不透明度内衬。 | 外径按位数为 27 / 35 / 44pt；描边 1.5pt；数字 15pt 中等字重。 | 最稳定、辨认最快；比短线多遮挡一点内容。 |
| 开口圆环 | 圆环右上方留一个小缺口，其余与完整环一致。 | 外径 27 / 35 / 44pt；环线 1.5pt；数字 15pt。 | 更轻，但缺口在缩小后的截图中可能不明显。 |
| 基线数字 | 彩色数字下方一根短底线；紧凑的近白色无边框衬底。 | 高约 29pt；宽按位数约 25 / 32 / 42pt；底线 1.5pt，左右各留约 5pt。 | 占位少；放在表格下划线附近时可能混淆。 |
| 引线数字 | 彩色数字右侧一根 10pt 水平细线；紧凑的近白色无边框衬底。 | 高约 27pt；宽按位数约 30 / 38 / 47pt；引线 1.5pt。 | 指向位置清楚；横向占位略大。 |

用户明确确认精修预览中的前三款：「精密圆环」「开口圆环」「基线数字」；不选「引线数字」。精密圆环为默认样式。红色仅用于预览；实际使用沿用用户选定的单色色盘颜色。数字衬底固定近白色，导出不随系统外观变化；样式本身不增加阴影、渐变或粗边框。

## 交互与数据规则

1. 工具架继续只放一个序号图标 `N`。`v0.0.10-alpha` 采用贴角双层操作区：序号工具激活或选中序号时，下排直接显示三款纯图标样式；名称通过悬停提示和辅助功能标签提供。`v0.0.9-alpha` 使用旧属性栏弹出面板。
2. 未选中序号时切换样式，改变以后新增序号的默认值并记住最近使用项；已选中序号时只改变该条样式，一次撤销可还原。颜色和样式独立修改。
3. 所有样式共用同一条数字序列。删除中间项后，后面的编号依次递补；切换样式、移动位置、调整截图选区均不重新排序。
4. 三款选定样式均以标记中心为点击锚点；切换样式时保持中心不动，避免标记跳位。
5. 绘制序号后工具仍激活，新标记选中；点击空白处继续放下一个编号，点击已有标记优先选择 / 移动，按住 `Option` 可覆盖放置。
6. 两位、三位数字增加标记宽度，不缩小字号；命中区域至少覆盖整个可见标记，短线样式还应有适当的额外点击容差。边界计算、选中框和导出使用同一几何。

## 当前选择与验收重点

- 检查三款在浅色、深色和复杂画面上的可读性；尤其观察开口环在 1x 屏幕上的缺口是否清楚。
- 检查数字变为 10、100 后是否居中、没有裁切；样式切换后标记中心是否保持不动。
- 检查截图与贴图再编辑中的同一标记外观、选中、移动、删除后重排和导出是否一致。

实现：`AnnotationStyle.counterStyle` 为每条标记保留样式；`CounterGeometry` 统一提供绘制和边界；`ToolbarView` 的纯图标三选项与 `Preferences.lastCounterStyle` 负责切换和默认值。截图与贴图编辑共用此模型。2026-11-01 工作区运行 226 项 Swift Package 测试且 Debug App 编译通过；未使用 UI 自动化，最终视觉由用户验收。

`v0.0.9-alpha` 首次提供三款序号样式，需在属性栏点击序号样式图标展开选项；`v0.0.10-alpha` 改为贴角双层直接点选。ad-hoc 构建覆盖安装后，macOS 可能要求重新授予屏幕录制权限并重启应用。
