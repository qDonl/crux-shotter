# 简洁分离工具架：实现与验证

日期：2026-10-31。

本文记录当日的历史验证结果。后续纯图标边角线控、实时线宽和连续绘制的设计与状态，见 [需求、界面决策与实现状态](product-decisions-and-status.md)；下方的 168 项测试数字仅对应当时的构建。

## 已实现

- 截图和贴图编辑共用竖向工具架、独立输出栏；工具按钮 32pt，实色中性表面、系统图标、单一强调色。复制与完成使用文字标签。
- 属性行预留固定尺寸，工具切换不移动输出栏；位置计算兼容侧边、上方和屏内避让，绘图架与输出栏优先保持分离。
- 选择按钮与 V 快捷键；截图 Esc 在退出前先回到选择模式。输入法文字编辑和标注选择仍优先处理 Esc。
- 贴图悬停操作条：编辑、复制、更多、关闭；延迟隐藏允许鼠标跨越间隙。关闭后仍可恢复；双击保留原关闭语义。
- 缩放与透明度 HUD 显示明确含义；开启穿透后提示恢复入口；菜单中的显示 / 隐藏文案跟随状态。
- 设置改为简单侧栏，保存目录与实时文件名预览支持长文本，目录选择使用 sheet；快捷键分组和行内冲突提示；更新未启用时显示原因。
- OCR 结果提供保留换行 / 合并单行选项、字符数和统一复制按钮；切换格式保留编辑原文，空内容不可复制。
- 权限引导按授权状态突出打开设置 / 重启；保留未重启时权限检测尚未生效的手动重启入口。
- 提示在光标所在屏幕显示，带操作时延长至 6 秒，悬停保留，完整详情可通过提示与辅助功能读取，减少动态效果时跳过淡出动画。

- 重新授予录屏权限后再次运行 `swift test --package-path CruxShotKit`：168 项测试全部通过；真实屏幕捕获测试 `snapshotHasOneFramePerScreen` 已执行并通过，本次没有跳过测试。
- 新增布局测试：普通选区、四角极小选区、全屏、负坐标屏幕，验证工具架与输出栏不越界、不重叠。
- 新增原生视图测试：不同工具下输出栏尺寸稳定，点击选择按钮不抢文字响应者；长保存目录下设置尺寸正常。
- 新增贴图隐藏回归：隐藏贴图时清理操作条悬停与延迟任务，父窗口不可见时拒绝残留悬停事件；组件测试确认不会挂载独立操作条。

- XcodeGen 生成与 Xcode Debug 全量构建成功；构建使用已有缓存依赖，未新增依赖。AppIntents 元数据提取提示为项目未依赖该框架的构建提示。
